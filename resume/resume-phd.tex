%----------RESEARCH INTERESTS----------
\section{Research Interests}
I want vision models that people can trust enough to actually deploy. Three questions keep coming up in my work. Can a clinician check what the model looked at, instead of taking a score on faith? How much of a black-box generative model's behavior can you control from the outside, without retraining it? And do learned representations hold up on scientific imaging, where the data looks nothing like ImageNet and the labels are noisy? I also build ML for a HIPAA-regulated clinical platform, so I run into the same questions with real patients on the other end.

%----------RESEARCH----------
\section{Research}

\projectHeadingPaper{MorphoCLIP: Text-Supervised Cell Painting Retrieval}
{https://github.com/suxrobgm/morphoclip}
{https://arxiv.org/abs/2608.22690}
\begin{itemize}
    \item Built a text-supervised contrastive model that matches Cell Painting microscopy images of drug- and gene-perturbed cells to descriptions of the treatment written in ordinary language. The vision and language backbones (DINOv3, BioClinical ModernBERT) stay frozen and only small projection heads train, which is what keeps the whole thing on a single consumer GPU.
    \item Tested retrieval in both directions, image-to-text and text-to-image, on the CPJUMP1 benchmark: 51 plates, 3M+ cell images, 303 drugs, 160 genes. Batch correction in the embedding space keeps the model from simply learning which plate an image came from.
    \item Collaborative work with Northeastern co-authors S.\ Gajjar and R.\ Jin; I led the model design, training, and evaluation.
    \item \textbf{Stack:} PyTorch, DINOv3, BioClinical ModernBERT, contrastive learning, CPJUMP1
\end{itemize}

\projectHeadingPaperOnly{Localize, Don't Beautify: Client-Side Control of Image-Editing APIs}
{https://arxiv.org/abs/2608.02841}
\begin{itemize}
    \item Ask a commercial image editor to change one feature of a face and it beautifies the whole thing. Cosmetic-surgery previews are where that goes wrong most visibly, which makes them a good test case for how much of a black-box model's behavior you can control from the outside.
    \item Compared prompt-only steering, masked compositing, and model-based inpainting across six commercial editors and one inpainting model, over 196 facelift and rhinoplasty edits, scored on identity preservation (ArcFace) and on whether the edit stayed where it was asked to. Plain masked compositing came out ahead of model-based inpainting on localization.
    \item \textbf{Stack:} Image-editing APIs, inpainting models, ArcFace, prompt engineering
\end{itemize}

\projectHeadingPaper{MelanomaNet: Explainable Deep Learning for Skin Lesion Classification}
{https://github.com/suxrobgm/explainable-melanoma}
{https://arxiv.org/abs/2512.09289}
\begin{itemize}
    \item Trained an EfficientNet V2 classifier across all 9 ISIC 2019 diagnostic categories at 384$\times$384, with focal loss to cope with the heavy class imbalance. It reaches 85.6\% accuracy and 0.856 weighted F1 on 25{,}331 dermoscopic images.
    \item Broke GradCAM++ attention down along the ABCDE criteria dermatologists already use, with asymmetry, border irregularity, color variation (K-means), and diameter measured straight off the lesion mask.
    \item Because those clinical features come out as numbers, how well they line up with the model's attention can be scored. The interpretability claim rests on a metric instead of a few good-looking heatmaps.
    \item \textbf{Stack:} PyTorch, EfficientNet V2, GradCAM++, OpenCV, focal loss, ISIC 2019
\end{itemize}

\section{Selected Course Projects}

\projectHeading{LightDepth: Lightweight Monocular Depth Estimation}
{https://github.com/suxrobgm/lightdepth}
\begin{itemize}
    \item Designed a ResNet18 encoder with a U-Net decoder and skip connections for monocular depth. It holds accuracy at 14.3M parameters where Depth Anything V2 needs 24.8M, a 42\% cut.
    \item Inference runs 72\% faster, and relative error on NYU Depth V2 improved too: 5.3\% on AbsRel, 31.1\% on SqRel.
    \item \textbf{Stack:} PyTorch, ResNet18, U-Net, NYU Depth V2
\end{itemize}

\projectHeading{FSRCNN: Accelerating Super-Resolution Convolutional Neural Network}
{https://github.com/suxrobgm/fsrcnn}
\begin{itemize}
    \item Reproduced FSRCNN (Dong et al., ECCV 2016) for single-image super-resolution at 2$\times$, 3$\times$, and 4$\times$. Upsampling is learned end to end, which is where the 40$\times$ speedup over SRCNN comes from.
    \item The reported gains held up on Set5 (+1.78\,dB PSNR, +0.0507 SSIM) and Set14 (+1.26\,dB PSNR, +0.0477 SSIM). Added ablations on the shrinking and mapping layers.
    \item \textbf{Stack:} PyTorch, mixed-precision training, T91/Set5/Set14/DIV2K
\end{itemize}

\projectHeading{Bookshelf Scanner: Multi-Modal Book Detection and Recognition}
{https://github.com/suxrobgm/bookshelf-scanner}
\begin{itemize}
    \item Point a camera at a bookshelf and get back a list of what is on it. YOLO instance segmentation cuts out each spine, then the Moondream2 vision-language model reads the title and author off it. Won the course Outstanding Project Award.
    \item \textbf{Stack:} YOLO, Moondream2 VLM, llama.cpp, PyTorch, FastAPI
\end{itemize}
